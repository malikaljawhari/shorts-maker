# Shorts Maker

Shorts Maker is a Python application that automates parts of the short-form video editing process.

It uses Streamlit for the user interface and FFmpeg for video processing. Users can import authorized footage, select timestamps, choose a video layout, add narration, generate subtitles, and export vertical MP4 videos.

The project also supports multiple text-to-speech options, including local neural voice generation with Kokoro.

## Why I built it

I wanted to explore how Python could automate repetitive video editing tasks while building practical experience with application development, media processing, and software integration.

The project began as an AI-assisted prototype that I've been configuring, testing, and improving as I learn more about the underlying technologies.

- Video upload and trimming
- Vertical video formatting
- Split-screen and blurred background layouts
- AI-generated narration
- Subtitle generation
- MP4 and SRT exporting
